k1k4k Jellyfin plugins

One plugin repository for all k1k4k plugins. Add it once to Jellyfin, and every plugin, with its updates, shows up in the catalog.
Un seul dépôt pour tous les plugins k1k4k : ajoutez-le une fois, chaque plugin et ses mises à jour apparaissent dans le catalogue.

Jellyfin Background Play

Leaving the web video player no longer stops the video: it keeps playing with the music mini player bar.
Quitter le lecteur ne coupe plus la vidéo : elle continue en fond avec la mini barre de la musique.

Jellyfin Player Queue

The play queue the web player was missing: seasons, reorder, add, remove, without leaving the video.
La file de lecture qui manquait au lecteur web : saisons, réordonner, ajouter, retirer, sans quitter la vidéo.
